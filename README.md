# Scribe AI

실시간 통신으로 음성을 받아 텍스트를 만들고, AI 요약과 RAG 검색까지 연결한 프로젝트입니다.

## 기술 스택

- Java 17
- Spring Boot 3
- WebSocket STOMP
- PostgreSQL
- pgvector
- Docker Compose
- Vanilla JS

## 프로젝트 소개
 
실시간 통신 WebSocket, AI 음성 인식, 요약 생성, RAG 검색 흐름을 한 서비스 안에서 연결했습니다.

- 실시간 자막
- 업로드 파일 요약
- 유튜브 자막 요약
- 요약 결과 검색
- 질문 답변 기능
- 간단 품질 평가 기능

## 서비스 흐름

### 1. 입력

입력 방법은 두 가지입니다.

- 실시간 모드  
  화면 오디오를 청크로 잘라 서버로 보냅니다.

- 배치 모드  
  파일 업로드 또는 유튜브 링크를 보냅니다.

### 2. 텍스트 만들기

서버에서 음성을 텍스트로 바꿉니다.  
유튜브는 자막을 읽어서 텍스트를 만듭니다.

### 3. 텍스트 정리

중복이나 잡음을 줄이는 전처리를 한 뒤,  
요약 모델로 구조화된 결과를 만듭니다.

구조화 결과 예시
- 제목
- 개요
- 정리 섹션
- 최종 요약
- 키워드

### 4. 저장

결과를 문서 단위로 DB에 저장합니다.

- documents
- document_summaries

### 5. 검색 준비

문서가 완료되면 RAG 인덱싱 작업을 큐에 넣습니다.  
워커가 큐를 읽어서 청크와 임베딩을 만듭니다.

- document_chunks
- rag_index_jobs

### 6. 질문과 답변

사용자가 질문을 입력하면

1. 질문 임베딩 생성  
2. 관련 청크 검색  
3. 검색된 내용으로 답변 생성

이 순서로 답변을 만듭니다.

## 주요 화면 기능

### 실시간 페이지

- 유튜브 영상 불러오기
- 듣기 시작, 듣기 중단
- 요약하기
- 실시간 원문 표시
- 요약 결과 표시
- 내용 검색
- 품질 평가

### 업로드 유튜브 페이지

- 파일 업로드 또는 유튜브 링크 입력
- 요약하기
- 결과 상태 확인
- 원문, 요약 결과 보기
- 내용 검색
- 품질 평가

## 품질 평가 기능

최대 5문항으로 자동 평가를 돌릴 수 있습니다.

- 성공률
- 평균 지연 시간
- p95 지연 시간
- 예상 호출량
- 문항별 성공 실패

## 주요 개발 사항

### 1. 실시간 통신과 배치 처리 동시 구현

- WebSocket STOMP로 실시간 오디오 청크를 받아 자막 생성
- 파일 업로드와 유튜브 링크 처리도 같은 서비스 안에 구성

### 2. AI 처리 흐름 구현

- 음성을 텍스트로 바꾸는 단계 구현
- 전처리 후 구조화 요약 생성
- 제목, 개요, 정리 섹션, 최종 요약, 키워드 형태로 결과 구성

### 3. RAG 검색 기능 구현

- 문서 텍스트를 청크로 분할
- 임베딩을 생성해 저장
- 질문이 들어오면 관련 청크를 찾고 답변 생성

### 4. 인덱싱 작업 백엔드 큐 처리

- 문서 완료 시 인덱싱 작업을 큐 테이블에 등록
- 워커가 큐를 읽어 인덱싱 진행
- 실패 시 재시도와 상태 기록 처리

### 5. 대화 메모리와 품질 평가 기능 추가

- 문서별 최근 질문 답변 메모리 유지
- 새로고침 시 메모리 초기화 처리
- 최대 5문항 자동 평가로 성공률, 지연 시간, 호출량 확인

## 폴더 구조

```text
src/main/java/com/scribeai
├── batch       # 파일/유튜브 배치 입력 처리
├── realtime    # 실시간 오디오 수신, 자막, 요약 처리
├── document    # 공통 문서 엔티티와 저장소
├── rag         # 청크 생성, 검색, 질문 답변, 평가
├── stt         # 음성 -> 텍스트 변환 provider
├── summarize   # 요약 생성 provider
└── common      # 공통 설정, 예외 처리, 텍스트 유틸(전처리)
```
